1 · Add the bubble

Include this script on the page where the calculator should appear. It creates the floating button and opens the hosted calculator in a responsive panel.

<script src="https://YOUR-SEVENTASK-DOMAIN/embed.js" data-position="right" defer></script>

Replace YOUR-SEVENTASK-DOMAIN with your deployed calculator domain. Use data-position="left" to place the bubble on the left.

2 · Call the API

Use your partner key from a trusted server. Do not put the API key in browser code or a public app bundle.

POST https://YOUR-API-DOMAIN/api/v1/calculate Content-Type: application/json X-API-Key: stk_live_YOUR_PRIVATE_KEY {"expression":"(18 * 24) + 10"} Response: {"result":442,"usage":{"used":1,"remaining":9999,"limit":10000}}

Allowed input: numbers, parentheses, +, −, ×, ÷, remainder and powers. The service parses expressions without evaluating arbitrary code.

API endpoints

  • GET /api/v1/health — service status
  • POST /api/v1/calculate — expression result and quota
  • GET /api/v1/usage — current monthly usage

Send the key in X-API-Key or Authorization: Bearer. Partner keys are shown once after verified checkout.
